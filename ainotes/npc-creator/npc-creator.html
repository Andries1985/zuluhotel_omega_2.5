Identity template id, look, name, script
Required. This becomes the block header, e.g. NpcTemplate etherealhorse. No spaces.
Primary Stats + Scaling STR/INT/DEX, HP path
STR is the base strength stat. BaseStrmod is an extra strength modifier applied after spawn. If HITS is filled, that's a direct HP value. If HITS is blank and CustomHitsLevel is unset, HP commonly follows STR + BaseStrmod. If CustomHitsLevel is set, shard scripts treat it as the HP override, commonly in hundredths (i30000 ≈ 300 HP). Use only one of these three paths.
Skills
A census of the live config/npcdesc.cfg found the same skill written in up to 4 different casings (e.g. MaceFighting / Macefighting / macefighting / MaceFigHting, 594 uses total) — the field parser is clearly case-insensitive here, so don't worry about exact capitalization.

AttackAttribute/AttackSpeed/AttackDamage are kept mainly for staff/Seer info display — shard AI scripts don't read them for standard killpcs-style combat. Real damage comes from the equipped weapon + weapon skill.

Example seen in-file: graphics 0x09 0 1 0 / graphics 0x18 0x0455 1 0 / graphics 0xc 0 0 1.

Generic key value rows, written at the top level (not inside CProp). Use this for any field this builder doesn't have a dedicated box for yet — a census of the live config/npcdesc.cfg file turned up 144 distinct top-level keys and this builder covers the real/common ones explicitly, but new or very rare ones can still be added here without waiting on a tool update.
Custom CProps protections, boss flags, anything else

Custom armor / wearable builder — itemdesc.cfg Armor/Item block

Real armor coverage pieces (helms, gorgets, chest, sleeves, gloves, leggings, shields) are Armor <objtype> { AR, Coverage, ... } blocks — 244 of them found across this repo's itemdesc-style files. Jewelry, robes, hats and other cosmetic wearables generally don't need AR/Coverage at all (nothing in this repo defines a "Layer" field — which body slot an item wears in is driven entirely by its graphic/objtype, not this config), so pick Plain wearable below for those and just give it a graphic plus optional magic bonuses via the CProp rows.
