# Zuluhotel Omega 2.5 - Copilot Instructions

## Project Context
This is a **POL (Perplex Online) Ultima Online Emulator** shard configuration and script collection.
- Engine: POL Server (https://github.com/polserver/polserver)
- Scripts: EScript language compiled with ecompile.exe
- Configuration: NPC/item/quest definitions via .cfg files

## Engine Authority Reference
For **any questions about engine limits, damage handling, vitals, or script functions**:
- **Primary source**: https://github.com/polserver/polserver
- **Critical modules**:
  - `pol-core/pol/module/vitalmod.cpp` - ApplyRawDamage, vitals, health/mana/stamina
  - `pol-core/pol/module/uomod.cpp` - UO object functions
  - `pol-core/pol/module/` - other system modules
  
## Known Constraints & Limits
- **ApplyRawDamage damage parameter**: max USHRT_MAX (65535)
  - Enforced in vitalmod.cpp: `damage >= 0 && damage <= USHRT_MAX`
  - Fails silently if damage exceeds this
- **CustomHitsLevel**: stored in hundredths; displayed HP = CustomHitsLevel / 100
- **Vital maximum values**: limited to range (100 to 10,000,000) hundredths

## Search Strategy
When looking up engine behavior:
1. Use `github_text_search` tool with `scope: "polserver/polserver"`
2. Search for function names (e.g., "mf_ApplyRawDamage") or constants
3. Combine with filename patterns when narrowing (e.g., `filename:vitalmod.cpp`)
